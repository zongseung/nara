새 비교 작업

기준 업체 품목마다 조건이 맞는 경쟁사를 찾아 가격비교표를 만듭니다.

기준 업체와 품목

법인격과 공백을 뺀 이름이 같은 제조업체 품목만 기준으로 잡습니다.

기준 업체 품목만 좁힙니다. 경쟁사는 품명으로 찾고 용도는 순위에만 반영합니다.

기본은 전체(0), 업체당 최대 10,000건. 일부 테스트는 3 등을 입력하세요.

조건이 맞는 후보가 없으면 칸이 비어 있습니다.

가격 비교 방식

가격 비교 방식

기본은 기준 단가보다 높은 후보를 고릅니다. 규격 검사는 유지하며, 촬영용으로 지지대 개수 검사를 임시 생략합니다.

기본은 1방향·2방향 차이를 허용합니다. 선택하면 알려진 방향 수도 같아야 합니다.

동일단가에서 같은 가격 후보가 하나도 없을 때만 씁니다.

검사와 후보 보충 기준

규격
가로와 세로 각각 ±10%. 600×150 mm면 가로 540~660, 세로 135~165 mm
지지대
촬영용 임시 생략. 미확인·개수 차이로 후보를 제외하지 않습니다.
재질
동일 명칭 → 같은 계열 → 혼합 재질 순으로 우선합니다. 미기재는 확인 필요, 명확히 다른 계열은 제외합니다.
표시면·설치
미기재는 확인 필요, 명확한 차이는 대안 후보로 표시합니다. 발광·반사 방식도 같습니다.
선정 순서
조건 충족 후보부터 선정하고 부족하면 확인 필요 → 대안 후보로 보충합니다. 열 배치는 가격 오름차순입니다.

지지대 개수 확인
직접 확인한 개수와 근거를 기록하면 해당 품목을 다시 비교합니다. 원천 정보는 보존합니다.

  
  
    

      
다른 후보 찾기

      

      
선택한 후보만 다시 찾습니다. 다른 후보와 기존 가격·규격 조건은 유지합니다.

      
      
비워두면 기존 조건으로 찾습니다. 입력한 재질을 포함하는 혼합 재질도 허용하며, 미확인 재질은 제외합니다.

      
대체 후보가 없으면 기존 후보를 유지합니다. 교체 후 가격순으로 열 위치가 바뀔 수 있습니다.
